# Longitudinal learning arc

An arc tests whether AbleArc adapts across time rather than replaying the same lesson.

## Identity

- Domain/topic:
- Target capability:
- Starting frontier hypothesis:
- Important learner self-report:
- What would falsify the starting model:

## Suggested shape

    S1 — locate a real frontier and create first capability
    S2 — retrieve without replay; extend or repair
    S3 — change representation / assumption / context
    S4 — transfer or delayed revisit when useful

The number of sessions is flexible. Cross-session dependence matters more.

## Across the arc

Track:

- whether AbleArc remembers useful context without repeating intake;
- whether scaffolding recedes;
- whether a misconception/model is revised when evidence changes;
- whether generated materials or visuals are actually used;
- whether understanding survives retrieval and representation/context changes.

## Outcome

Choose one:

- capability_gain_supported
- partial_gain_unstable
- no_clear_gain
- teaching_failure_dominant
- insufficient_evidence

Then record:

- What changed in the learner?
- Which intervention had the strongest evidence of value?
- Which failure repeated?
- Is a Skill rule change justified?
- What remains uncertain?
