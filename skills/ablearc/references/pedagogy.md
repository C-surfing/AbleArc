# Pedagogy reference

Use this file when a topic needs more deliberate instructional design than the compact rules in SKILL.md.

## Sequencing

Sequence by dependency and cognitive leverage, not textbook chapter order.

A useful route often looks like:

    motivating problem
    → prerequisite only when needed
    → concrete mechanism
    → formalization
    → use
    → transfer

Do not front-load every prerequisite just in case.

## Scaffolding

Provide the minimum support that keeps the learner doing the important reasoning.

Possible scaffold levels:

1. open attempt;
2. narrow the task;
3. provide a cue;
4. provide a partial structure;
5. worked example;
6. direct explanation.

Move down the list only when needed. Remove scaffolding once it stops being necessary.

## Feedback loops

Good feedback should usually identify:

- what worked;
- what failed;
- why it failed;
- what to do next.

It should be information-rich without becoming a second lecture.

## Active learning

Prefer learner generation when the act of generating is the skill:

- predict before revealing;
- derive before showing a derivation;
- reconstruct a mechanism;
- debug an incorrect explanation;
- compare two cases;
- implement a bounded piece;
- teach back in the learner's own model.

Do not use active learning as a ritual when direct explanation is more efficient.

## Motivation

Motivation is not points, streaks, or cheerleading.

Useful motivation comes from:

- seeing why a problem matters;
- understanding where the current idea fits;
- challenge near the learner's frontier;
- visible progress in capability;
- autonomy over direction;
- well-timed expansion into interesting adjacent ideas.

## Challenge calibration

Use qualitative judgment:

- underloaded;
- productive;
- overloaded;
- unknown.

Underloaded: remove scaffolding, vary context, apply, or transfer.

Productive: preserve the current difficulty.

Overloaded: narrow the move, repair one prerequisite, provide an example, or reduce irrelevant complexity.

Unknown: choose a discriminative move.

Do not optimize for a fixed error rate.

## Representation choice

Choose the representation that best exposes the target structure.

Possible representations include prose, analogy, numeric example, equation, code, table, diagram, timeline, counterexample, and simulation.

Switch representation when the current one is causing friction rather than understanding.
