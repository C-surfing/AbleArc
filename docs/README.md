## Design references under audit

Some documents remain because they contain potentially useful learning ideas developed before the Skill-first reset: Evidence, LearningMap, paper learning, teaching taste, research, practice progression, and related deterministic utilities.

They are **references, not installation requirements or current product architecture**.

During cleanup, keep a document or utility only if real Skill usage shows that it improves learning or protects a necessary invariant. Git history is sufficient storage for retired product architecture.
