# AbleArc UI Reference Library

References are pattern sources, not templates to clone.

## Brilliant / Refero

- Refero Brilliant flows: https://refero.design/search/flows?site_id%5Bid%5D%5B%5D=221
- Brilliant: https://brilliant.org/

Borrow:
- single-step decision rhythm;
- generous whitespace;
- playful but clear learning feedback;
- learning visuals as part of pedagogy;
- restrained progress indication.

Do not borrow:
- brand green;
- mascot/course-marketplace identity;
- heavy gamification.

## Linear

- UI redesign notes: https://linear.app/changelog/2024-03-20-new-linear-ui

Borrow hierarchy, balance, density, navigation discipline, and reduction of visual noise.

## NotebookLM

- Workspace redesign: https://blog.google/innovation-and-ai/models-and-research/google-labs/notebooklm-new-features-december-2024/

Borrow task-dependent Sources / learning / supporting-workspace expansion. Do not require permanent three-column layout.

## Claude Artifacts

- https://support.claude.com/en/articles/9487310-what-are-artifacts-and-how-do-i-use-them

Borrow the idea that durable learning objects can leave the chat stream and become first-class workspace objects.

## Granola

- https://www.granola.ai/blog/announcement

Borrow provenance: learner-authored material must remain visibly distinct from model-added structure.

## Readwise Reader

- https://docs.readwise.io/reader/docs/faqs/appearance

Borrow reduced chrome and side-panel retreat during focused reading/learning.

## Raycast

- https://manual.raycast.com/ai/quick-ai

Borrow intent-first interaction and low-friction entry. Input should start an action, not merely append another chat message.

## Heptabase

- https://heptabase.com/

Borrow spatial knowledge structure for later Map refinement. Do not make the knowledge map the default home page.

## AbleArc synthesis

Brilliant supplies **life**.
Linear supplies **discipline**.
NotebookLM supplies **adaptive workspace structure**.
Claude supplies **object permanence outside chat**.
Granola supplies **provenance**.
Readwise supplies **focus**.
Raycast supplies **intent-first entry**.

The result should look recognizably AbleArc rather than like any one reference.
